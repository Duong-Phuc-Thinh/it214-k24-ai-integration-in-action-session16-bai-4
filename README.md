# Quan ly Cache E-commerce (Spring Boot & Python Simulation)

## Gioi thieu
Day la bai tap ve chien luoc cap nhat cache trong he thong thuong mai dien tu voi ty le doc/ghi la 100:1.
He thong su dung Redis lam Distributed Cache.

## Chuc nang da lam
- Phan tich va so sanh hai chien luoc `@CachePut` va `@CacheEvict`.
- Xay dung mo phong ProductService bang Python.
- Xu ly loi khi thao tác cache that bai (Redis down, timeout) va co che TTL.

## Huong dan chay chuong trinh
Chay file python chinh bang lenh:
```bash
python main.py
```
